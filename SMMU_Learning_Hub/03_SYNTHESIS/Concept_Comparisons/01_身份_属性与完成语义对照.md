# 身份、属性与完成语义对照

> 更新日期：2026-09-10  
> 状态：跨主题比较，待追问验证。

## 身份：来源、地址空间和消息不能混淆

| 名称 | 主要用途 | 不能直接等同 |
|---|---|---|
| SID | 选择 Stream/STE | 固定一颗物理设备或进程 |
| SSID / PASID | 选择 Substream/CD 的相关身份 | OS PID 或 ASID |
| ASID | Stage 1 地址空间标签 | 页表里的每个 PTE 字段 |
| VMID | Stage 2/VM 上下文标签 | MECID |
| BAS TID/TDEST | 消息身份与返回路由 | SID/ASID，或全局永久流水号 |
| Token | 请求容量授权 | 任一身份 ID |

## 属性：同样写 Inner/Outer，不表示同一个维度

| 属性 | 作用对象/问题 |
|---|---|
| PTE.AttrIndx → MAIR | 映射数据的 memory type/cache policy |
| PTE.SH | 映射数据的适用 Shareability |
| CD.IR/OR/SH | 页表遍历自身的访问属性 |
| AxCACHE / AxDOMAIN | 总线侧内存/共享域表达，受产品转换规则限制 |
| SEC_SID | 输入 Stream 安全上下文 |
| 输出 PAS / MECID | 目标安全物理地址空间 / 加密上下文 |

概念正交不等于所有组合均合法；总线转换也不保证逐字段无损透传。

## 完成：每一种确认只证明自己的范围

| 观察点 | 能证明 | 不能直接证明 |
|---|---|---|
| TLBI/CFGI 被 CONS 越过 | 命令已消费 | 失效效果完成 |
| 目标 CMD_SYNC 被正常消费 | 其架构完成保证满足 | 所有设备 DMA 停止或 PRI 响应已到 Endpoint |
| INV_ACK | 失效请求的流控确认 | 先前全部失效效果完成 |
| DTI SYNC_ACK | 先前相关失效完成 | 其他独立队列/设备所有工作完成 |
| PRIQ_CONS 前进 | 软件消费队列记录 | 软件已回复设备 |
| PAGE_ACK / RESPACK | 对应消息接收确认 | 页面成功准备 |
| PAGE_RESP | 软件处理结果 | 无条件成功 |
