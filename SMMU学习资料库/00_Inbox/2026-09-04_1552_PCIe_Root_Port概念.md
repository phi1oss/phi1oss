# PCIe Root Port 概念

## 核心定义

**Root Port 是 PCIe Root Complex 向下连接 PCIe Fabric 或 Endpoint 的一个具体端口。**

可以理解为：

```text
CPU / Memory System
        ↓
   Root Complex
    ├─ Root Port 0 → PCIe Endpoint
    ├─ Root Port 1 → PCIe Endpoint
    └─ Root Port 2 → PCIe Switch
```

## Root Complex 与 Root Port 的关系

```text
Root Complex
→ 整个 PCIe 根节点 / Host 侧功能块

Root Port
→ Root Complex 中面向某一条 PCIe Link 的具体下行端口
```

所以：

> **Root Complex 是“整套根节点”，Root Port 是“其中一条具体 PCIe 出口”。**

## Root Port 的作用

Root Port 负责某条 PCIe Link 上的 transaction 收发，把 Endpoint 一侧的 PCIe TLP 接入 Root Complex / SoC：

```text
PCIe Endpoint
   ↓ TLP
Root Port
   ↓
Root Complex / SoC
```

反方向：

```text
CPU / SoC
   ↓
Root Port
   ↓
PCIe Endpoint
```

## 与 PCIe bifurcation 的关系

例如一个 x16 PCIe Controller 做 bifurcation：

```text
x16
↓
x8 + x8
```

系统可形成两个独立 Root Port，每个 Root Port 管理自己的一条 PCIe Link 和对应 requester transaction。

对 SMMU 来说，这些不同 Root Port 下的 Device transaction 后续需要通过 SID、TBU/LTI 或 DTI-ATS 等路径接入 translation system。

## 一句话记忆

> **Root Complex 是“PCIe 总部”，Root Port 是“总部下面的一条具体 PCIe 出口”。**
