# RDC 学习资料库

用于持续收录和整理 Reset Domain Crossing（RDC）相关问答、工具实践和项目经验。

## 目录

- `00_Inbox/`：按实际收录时间保存尚未专题化整理的 ChatGPT 回答。
- 后续按内容成熟度逐步增加专题目录，例如：
  - `01_基础概念/`
  - `02_Setup与约束/`
  - `03_Violation分析/`
  - `04_RTL修复/`
  - `05_Waiver与Signoff/`

## Inbox 命名规范

```text
YYYY-MM-DD_HHMM_主题.md
```

时间采用北京时间（UTC+8）。
